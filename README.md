# 선형회귀 예측 웹앱

CSV를 업로드하고 독립변수/종속변수를 선택해 선형회귀 모델을 학습하고 새 값을 예측하는 Streamlit 웹앱입니다.

## 내 컴퓨터에서 실행하기

1. Python 3.10 이상을 설치합니다.
2. 압축을 푼 폴더에서 터미널/명령 프롬프트를 엽니다.
3. 아래 명령어를 실행합니다.

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 표시되는 로컬 주소(보통 `http://localhost:8501`)로 접속합니다.

## 공개 웹사이트로 배포하기

이 폴더를 GitHub 저장소에 올린 뒤 Streamlit Community Cloud에서 새 앱을 만들고 `app.py`를 지정해 배포할 수 있습니다. 배포 과정에서 GitHub 및 호스팅 서비스 계정 로그인이 필요할 수 있습니다.

- Streamlit 배포 안내: https://docs.streamlit.io/deploy/streamlit-community-cloud
- 앱은 업로드된 데이터를 외부 서비스로 전송하는 별도 코드를 포함하지 않습니다. 다만 공개 배포 시 민감하거나 개인 식별 가능한 데이터는 업로드하지 마세요.

## CSV 형식 예시

첫 행은 열 이름이어야 하며, 모델에 사용할 독립변수와 종속변수는 숫자형이어야 합니다.

```csv
광고비,방문자수,할인율,매출
100,500,5,1200
150,650,10,1600
200,800,5,2100
250,900,15,2500
300,1100,10,3100
```

예시 데이터는 기능 테스트용일 뿐 실제 모델 성능을 보장하지 않습니다.
